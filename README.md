# Tutorial educacional de Local File Inclusion (LFI)

Página estática, responsiva e interativa para o ensino de LFI em ambientes controlados e testes autorizados.

## GitHub Pages

O site está em `docs/` e pode ser publicado diretamente pelo GitHub Pages:

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch principal e a pasta **`/docs`**.
4. Salve e aguarde a URL pública ser criada.

O tutorial não executa PHP. O simulador funciona apenas no navegador e não acessa arquivos reais.

## Segurança do material

O laboratório PHP vulnerável e o guia do professor são mantidos fora deste repositório público. Pratique somente em sistemas próprios, máquinas virtuais isoladas ou ambientes com autorização expressa.
